# Save a view and reopen it

## Brief

The feature's floor: name the filters you are looking at and get them back from a list, dates
included, so the same three filters are not retyped every month.

## What to build

Name the filters you are looking at, and get them back from a list.

## Acceptance criteria

- [ ] reopening a view restores every filter, including the date range
- [ ] Property P1, reviewed: a reopened view restores every filter it was saved with, the dates included
