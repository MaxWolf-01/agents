# The shape of the view list

## Brief

Rows, cards or a sidebar, what a view shows before you open it, and where "share" sits. A surface
judgment does not sharpen as other calls land, only in front of something rendered, so three takes
are built over the same twelve views and you rule there.

## Acceptance criteria

- [ ] One take is chosen, and promoted as the floor the slices that draw the list build to.
- [ ] Takes outside these three count, if one in front of you suggests it.

## Questions

- [D1] **Rows, cards, or a sidebar for the list of saved views?** Rows fit forty views on a screen and say least about each; cards show a view's filters before it opens; a sidebar keeps the list beside the entries it filters. The pick lays the floor `save-and-reopen-a-view` draws on.
