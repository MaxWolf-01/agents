# Keep the filters across a reload

## Brief

The filter value goes into the page's address, so a reload or a pasted address opens on the same rows.
The smallest thing user story 4 asks, and a link before there is anything to name.

## Acceptance criteria

- [ ] A reload keeps every filter, the date range included.
