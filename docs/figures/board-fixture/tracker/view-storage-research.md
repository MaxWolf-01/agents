# Where saved views are stored

## Brief

Saving and sharing both wait on one storage answer: whether a filter set is a column on the account
or a table of its own, and what each costs once a view is shared and renamed. The answer lands in the
parent ticket's Decisions.

## Acceptance criteria

- [ ] The parent ticket's Decisions say where a view is stored, with what the other store would have cost.
