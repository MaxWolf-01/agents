A ticket's flow: where each status is written, and by which command

A ticket's status is a field in its file in the agent repo, and the sessions on your machine write it: a session you sit at, and the orchestrator, which holds the branch the tickets merge into; often they are one session. Each line into a status starts at the command that writes it, in the row where that command is typed. Workers build on hosts of their own and write no ticket file. Nothing moves back from done.
