mx tracker · ticket state

Every ticket holds one state, and each transition has exactly one writer.

Tickets are markdown files under agent/tickets/; the board is the whole tracker rendered as one page. Every ticket an agent writes is proposed: on the frontier and built like any other, in its own colour in every view, until you rule on what it produced. Everything the page shows — the dependency graph, the frontier, the review pages, everything that waits on you — is derived from those files, so the page is never a second place to keep state.
