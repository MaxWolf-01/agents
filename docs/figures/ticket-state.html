mx tracker · ticket state

Every ticket holds one state, and each transition has one writer.

A ticket is one markdown file, agent/tickets/<slug>.md in the agent repo, and a parent: line makes it a child ticket of another, so the tickets form trees. tracker refuses any status change its rules forbid. A worker never writes a ticket file: the orchestrator imports the report the worker commits. The board is rendered from these files and keeps no state of its own.
