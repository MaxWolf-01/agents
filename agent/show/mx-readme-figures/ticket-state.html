mx tracker · ticket state

Every ticket holds one state, and each transition has exactly one writer.

Tickets are markdown files under agent/tickets/; the board is the whole tracker rendered as one page. An agent that spots work nobody asked for files it as proposed: off the frontier, in its own colour in every view, until you rule on it. Everything the page shows — the dependency graph, the frontier, the wave lanes, the review pages, the queue — is derived from those files, so the page is never a second place to keep state.
